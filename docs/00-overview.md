# Dvmbr Community App Overview

## 프로젝트 개요

`dvmbr-community-app`은 스트리머와 시청자를 위한 익명 커뮤니티 웹 서비스 MVP입니다.

사용자는 플랫폼과 주제별 게시판에서 익명 ID로 글과 댓글을 작성할 수 있습니다. 관리자는 익명으로 노출된 활동 뒤의 실제 회원 정보를 확인하고 신고, 블라인드, 제재 처리를 할 수 있습니다.

## 프로젝트 목적

이 프로젝트의 1차 목적은 커뮤니티 서비스의 핵심 구조를 직접 설계하고 구현하는 것입니다.

중점적으로 다루는 범위는 다음과 같습니다.

- 회원가입 / 로그인
- 역할 기반 권한 관리
- 고정 익명 ID
- 게시판 / 댓글
- 추천 / 비추천
- 신고 / 블라인드
- 관리자 페이지
- PostgreSQL 기반 DB 모델링
- Docker 기반 로컬 개발 환경
- AWS 배포 가능 구조

## 핵심 설계 방향

### 1. 익명성과 운영 추적성 분리

사용자 화면에는 `익명팬#0000`, `익명BJ#0000`과 같은 익명 ID를 표시합니다.

하지만 DB에는 게시글과 댓글의 실제 작성자 ID를 저장합니다. 이를 통해 일반 사용자에게는 익명성을 제공하면서도, 관리자는 신고 처리나 제재가 필요한 경우 실제 회원을 추적할 수 있습니다.

### 2. MVP 우선 개발

외부 플랫폼 실시간 데이터 수집, 후원 랭킹, 큰손탐지기 같은 기능은 API 정책과 데이터 접근성이 중요하므로 2차 기능으로 분리합니다.

1차 MVP에서는 외부 의존성이 낮고 서비스의 기본 운영에 필요한 기능을 먼저 구현합니다.

### 3. 운영 가능한 커뮤니티 구조

익명 커뮤니티는 단순 게시판보다 운영 기능이 중요합니다.

따라서 신고, 블라인드, 관리자 조회, 회원 제재 기능을 초기 설계에 포함합니다.

## 1차 MVP 범위

1차 MVP에서는 다음 기능을 구현합니다.

- 이메일 기반 회원가입 / 로그인
- JWT 기반 인증
- 회원 역할 구분
- 유저별 고정 익명 ID 생성
- 게시판 목록 / 게시글 작성 / 게시글 조회
- 댓글 / 대댓글
- 추천 / 비추천
- 신고 접수
- 신고 누적 또는 관리자 처리 기반 블라인드
- 관리자 페이지

## 2차 확장 범위

다음 기능은 1차 MVP 이후 확장합니다.

- 소셜 로그인
- 휴대폰 본인 인증
- 스트리머 / 기업회원 인증 고도화
- 플랫폼별 실시간 방송 데이터 수집
- 플랫폼별 랭킹
- 후원 데이터 기반 큰손탐지기
- 업체존
- 구인구직
- 중고장터
- S3 기반 파일 업로드
- AWS 운영 배포

## 초기 개발 목표

첫 번째 개발 목표는 다음 사용자 흐름을 완성하는 것입니다.

1. 사용자가 회원가입한다.
2. 로그인 시 JWT 토큰을 발급받는다.
3. 회원 생성 시 고정 익명 ID가 함께 생성된다.
4. 사용자가 게시글을 작성한다.
5. 게시글 목록에서는 실제 이름이 아니라 익명 ID가 표시된다.
6. 관리자는 게시글 작성자의 실제 회원 정보를 확인할 수 있다.
